# Agentic SDLC: Building a Software Factory

A hands-on course where I build a set of AI agents with Kiro CLI that automate
the software development lifecycle: Git workflow, architecture design,
requirements, CI/CD and testing. In the final project, all agents work together
as a software factory on a single kata.

## Course Progress

- [ ] Module 1: Git — workflow agent
- [ ] Module 2: Software Architecture — arc42 design agent
- [ ] Module 3: Software Requirements — user story derivation agent
- [ ] Module 4: CI/CD — deployment pipeline agent
- [ ] Module 5: TDD/BDD — multi-agent test system
- [ ] Module 6: Final Project — individual kata using all agents
